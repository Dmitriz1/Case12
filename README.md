# HTTP Expenses Tracker API

Основной HTTP-сервер для учёта трат.

Сервер реализован на чистом `http.server.BaseHTTPRequestHandler` и хранит данные в MongoDB.  
Поддерживаются операции CRUD и простая агрегация статистики.

## 1. Главная страница

- **Метод:** `GET`  
- **Путь:** `/`  
- **Параметры:** отсутствуют  
- **Ответ:**
  - `200 OK`  
  - `Content-Type: text/html; charset=utf-8`  
  - Возвращает файл `index.html`

## 2. Получить все траты

- **Метод:** `GET`  
- **Путь:** `/expenses`  
- **Параметры:** отсутствуют  
- **Ответ:**
  - `200 OK`  
  - `Content-Type: application/json`  
  - Тело: массив документов MongoDB:
    ```json
    [
      {
        "_id": "ObjectId",
        "expense_name": "string",
        "category": "string",
        "amount": "string",
        "date": "YYYY-MM-DD"
      },
      …
    ]
    ```
  - `524 Gateway Timeout` — таймаут подключения к БД

---

## 3. Самая дорогая категория за месяц

- **Метод:** `GET`  
- **Путь:** `/stats/most-expensive-category`  
- **Query-параметры:**
  - `month` (обязательный) — месяц в формате `"MM"` (например, `03`)  
- **Ответ:**
  - `200 OK`  
  - `Content-Type: application/json`  
  - Тело:
    ```json
    {
      "category": "string",                 // категория с наибольшей суммой
      "total_amount": number,               // общая сумма по этой категории
      "expense_name": "string",             // название самой крупной траты в месяце
      "total_amount_expanse_name": number,  // сумма этой траты
      "total_amount_category": number       // сумма самой крупной траты в самой дорогой категории
    }
    ```
  - `204 No Content` — если за указанный месяц нет записей  
  - `524 Gateway Timeout` — таймаут подключения к БД

## 4. Самая крупная трата в категории за месяц

- **Метод:** `GET`  
- **Путь:** `/stats/biggest-expense`  
- **Query-параметры:**
  - `month` (обязательный) — месяц в формате `"MM"`  
  - `category` (обязательный) — имя категории  
- **Ответ:**
  - `200 OK`  
  - `Content-Type: application/json`  
  - Тело:
    ```json
    {
      "name": "string",   // название траты
      "amount": number,   // сумма
      "date": "YYYY-MM-DD"
    }
    ```
  - `204 No Content` — если нет подходящих записей  
  - `524 Gateway Timeout` — таймаут подключения к БД

## 5. Список категорий по месяцу

- **Метод:** `GET`  
- **Путь:** `/stats/categories-by-month`  
- **Query-параметры:**
  - `month` (обязательный) — месяц в формате `"MM"`  
- **Ответ:**
  - `200 OK`  
  - `Content-Type: application/json`  
  - Тело: массив строк — списка категорий, в которых были траты:
    ```json
    ["food", "transport", "entertainment", …]
    ```
  - `524 Gateway Timeout` — таймаут подключения к БД

## 6. Добавить новую трату

- **Метод:** `POST`  
- **Путь:** `/`  
- **Content-Type:** `application/x-www-form-urlencoded`  
- **Form-параметры:**
  - `expense_name` — название траты (string)  
  - `category` — категория (string)  
  - `amount` — сумма (string, число)  
  - `date` — дата в формате `YYYY-MM-DD`  
- **Ответ:**
  - `303 See Other`  
  - Заголовок `Location: /` — перенаправление на главную страницу  
  - `524 Gateway Timeout` — таймаут подключения к БД

---

## 7. Удалить трату по ID

- **Метод:** `DELETE`  
- **Путь:** `/expenses/{id}`  
- **Параметры:**
  - `{id}` — `ObjectId` документа в MongoDB  
- **Ответ:**
  - `204 No Content` — удалено успешно  
  - `404 Not Found` — документ не найден  
  - `524 Gateway Timeout` — таймаут подключения к БД

---

## 8. Обновить трату по ID

- **Метод:** `PUT`  
- **Путь:** `/expenses/{id}`  
- **Content-Type:** `application/json`  
- **Параметры:**
  - `{id}` — `ObjectId` документа  
  - Тело: JSON с полями для обновления, например:
    ```json
    {
      "expense_name": "Новое имя",
      "amount": "1500"
    }
    ```
- **Ответ:**
  - `200 OK` — обновлено успешно  
  - `400 Bad Request` — некорректный JSON  
  - `504 Gateway Timeout` — таймаут подключения к БД  
  - `404 Not Found` — маршрут не найден (если путь неверен)

## Статические файлы

- Путь: `/static/css/...` — отдает CSS (`text/css; charset=utf-8`)  
- Путь: `/static/js/...` — отдает JavaScript (`application/javascript; charset=utf-8`)  
- Путь: `/static/img/...` — отдает изображения (`image/png`)  
- Несуществующие файлы возвращают `404 Not Found`
